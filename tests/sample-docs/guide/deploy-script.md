# 배포 스크립트 사용법

배포는 저장소에 포함된 스크립트 하나로 수행한다.

## 기본 실행

아래 순서로 실행한다. 각 줄 앞의 주석은 설명이며 입력하지 않는다.

```bash
# 1. 대상 환경을 고른다
export TARGET_ENV=staging

# 2. 이미지 태그를 지정한다
export IMAGE_TAG=v1.4.2

# 3. 배포를 실행한다
./deploy.sh
```

스크립트는 환경변수가 비어 있으면 즉시 종료한다. 기본값을 두지 않는 이유는
의도하지 않은 환경에 배포되는 사고를 막기 위해서다.

## 롤백

```bash
# 직전 리비전으로 되돌린다
./deploy.sh --rollback
```

롤백은 직전 한 단계만 지원한다. 그 이전으로 돌아가려면 태그를 직접 지정해 재배포한다.
