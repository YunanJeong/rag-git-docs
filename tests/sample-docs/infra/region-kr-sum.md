# kr-sum 리전 구성

kr-sum 은 배치 작업과 분석 워크로드를 받는 보조 리전이다.

## 서버 식별자 체계

kr-sum 의 serverid 는 `krs-` 접두사로 시작한다. kr-mum 과 번호 대역이 겹치지 않도록
발급 범위를 분리해 두었다.

## 로그 DB 연결

kr-sum 의 log DB 는 분석 질의가 길게 도는 것을 전제로 타임아웃이 넉넉하게 잡혀 있다.
운영 리전과 같은 값으로 맞추면 배치가 중간에 끊긴다.

## 용도 제한

kr-sum 에 사용자 트래픽을 직접 태우지 않는다. 용량 산정이 배치 기준이라 응답 지연이
운영 기준을 만족하지 못한다.
