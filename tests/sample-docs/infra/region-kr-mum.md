# kr-mum 리전 구성

kr-mum 은 국내 주 서비스 트래픽을 받는 리전이다.

## 서버 식별자 체계

kr-mum 의 serverid 는 `krm-` 접두사로 시작한다. 이력 승계 대상이며 인스턴스를 교체해도
serverid 는 유지한다. 교체 시 새 값을 발급하면 통계가 끊긴다.

## 로그 DB 연결

kr-mum 의 log DB 는 리전 내부 엔드포인트로만 접근한다. 외부에서 직접 붙는 경로는 없다.
접속 정보는 배포 파이프라인이 주입하며 저장소에 두지 않는다.

## 장애 시 전환

kr-mum 이 내려가면 트래픽은 대기 리전으로 넘어간다. 전환은 자동이 아니며 운영자가
수동으로 승인한다.
